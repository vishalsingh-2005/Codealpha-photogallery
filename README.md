# 📸 VividFrame — Photo Gallery

VividFrame is a responsive photo gallery website built using HTML, CSS, and JavaScript. It showcases images across different categories with a clean and interactive user interface.

## ✨ Features

- Responsive photo gallery layout
- Multiple image categories: Animals, Cities, Nature, and Technology
- Interactive gallery powered by JavaScript
- Custom styling with CSS
- Image-based visual browsing
- Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Interactive functionality

## 📂 Project Structure


## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vishalsingh-2005/Codealpha-photogallery.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No additional dependencies are required.
